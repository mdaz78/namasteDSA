Time & Space Complexity · Lesson 2

From Loops to Big-O: Linear & Nested

The win: given any arrangement of for loops, you can write down the step-count and reduce it to Big-O — using your own repo code.

Recall from Lesson 1: find the operation that runs most often, write how many times it runs in terms of n, then drop constants and drop lower-order terms. This lesson is step 2 — getting the count out of the code.

1. Single loop → O(n)

Your warmUp/searchElement.js:

function searchElement(arr, element) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === element) {   // runs at most n times
      return i;
    }
  }
  return -1;
}

The loop visits each of the n elements once. The comparison inside runs at most n times → O(n).

Best case vs. worst case

If element is at index 0, the function returns after one comparison — that is the best case, O(1). If it is last or missing, you do all n comparisons — the worst case, O(n).

In interviews, "what's the complexity?" means the worst case unless you say otherwise (glossary: worst case). So: searchElement is O(n).

2. Two loops in a row → still O(n)

function report(arr) {
  for (let i = 0; i < arr.length; i++) { console.log(arr[i]); }   // n
  for (let i = 0; i < arr.length; i++) { console.log(arr[i]*2); } // n
}

Sequential loops add: n + n = 2n. Drop the constant → O(n). Two passes, ten passes, a hundred passes — as long as the count is a fixed multiple of n, it stays linear.

The pattern: loops side by side add. Loops nested inside each other multiply. That one distinction drives most of this lesson.

3. Nested loop → O(n²)

Your starPatterns.js, pattern1:

const pattern1 = (n) => {
  for (let i = 0; i < n; i++) {
    let row = "";
    for (let j = 0; j < n; j++) {
      row += "* ";        // runs n * n times
    }
    console.log(row);
  }
};

For each of the n outer passes, the inner loop runs the full n times. Multiply: n × n = n² → O(n²).

4. The trap: a triangular nested loop → still O(n²)

Your pattern2 — note the inner condition j <= i:

const pattern2 = (n) => {
  for (let i = 0; i < n; i++) {
    let row = "";
    for (let j = 0; j <= i; j++) {   // runs i+1 times, NOT n times
      row += "* ";
    }
    console.log(row);
  }
};

Here the inner loop runs 1, 2, 3, … , n times as i grows. Total steps:

1 + 2 + 3 + … + n = n(n + 1) / 2 = n²/2 + n/2

Now apply the rules: drop the lower-order n/2, drop the constant 1/2 → O(n²).

5. Two different sizes → O(n · m)

function pairUp(users, posts) {
  for (let u = 0; u < users.length; u++) {    // n
    for (let p = 0; p < posts.length; p++) {  // m
      link(users[u], posts[p]);
    }
  }
}

When the two loops range over different inputs, don't collapse them into one letter. This is O(n · m). Only write O(n²) when both loops genuinely run the same n times.
