The two simplification rules

1. Drop constants

O(2n) = O(n).   O(n/2) = O(n).   O(500) = O(1).

2. Drop lower-order terms

O(n² + n) = O(n²).   O(n + log n) = O(n).   Keep only the fastest-growing term.

Space complexity — don't forget

  • Count extra memory the algorithm allocates, as a function of n. Not the input itself.
  • A few variables → O(1) ("in place").
  • A new array/map holding n items → O(n).
  • Recursion call stack counts: depth d → O(d) space, even if each frame is tiny.
  • The output can count, depending on how the interviewer scopes the question — say your assumption out loud.
