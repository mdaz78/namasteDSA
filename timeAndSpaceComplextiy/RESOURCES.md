# Time & Space Complexity Resources

<!-- Readable/styled version for browsing: reference/resources.html -->

Curated, high-trust sources. Knowledge in the lessons is drawn from here, not from guesses.

## Knowledge

- [Big-O Cheat Sheet (Eric Rowell) — bigocheatsheet.com](https://www.bigocheatsheet.com/)
  The canonical one-page visual: growth-rate chart plus best/avg/worst tables for every
  common data structure and sorting algorithm. Use for: quick lookup, the "which is
  faster" ranking, sorting-algorithm complexities.

- [Interview Cake — "Big O Notation: Time & Space Complexity"](https://www.interviewcake.com/article/java/big-o-notation-time-and-space-complexity)
  Interview-focused explainer. Strong on *how to talk about* complexity, drop constants,
  worst vs. best case, and space complexity. Use for: framing analysis the way an
  interviewer wants to hear it.

- [MIT OpenCourseWare 6.006 — Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)
  Primary academic source. Lectures 1–2 cover asymptotic notation and models of
  computation rigorously. Use for: when an intuition needs a solid foundation.

- Book: *A Common-Sense Guide to Data Structures and Algorithms* by Jay Wengrow (2nd ed.)
  The clearest beginner-to-interview bridge on Big-O. Chapters 1–4 are exactly this
  mission. Use for: worked examples, building intuition before formalism.

- Book: *Introduction to Algorithms* (CLRS), Cormen/Leiserson/Rivest/Stein — Ch. 3
  The reference definition of Θ, O, Ω. Use for: precise definitions, later recurrence work.

- [freeCodeCamp — "Big O Cheat Sheet: Time Complexity Chart"](https://www.freecodecamp.org/news/big-o-cheat-sheet-time-complexity-chart/)
  Free, readable summary with JS-flavoured examples. Use for: a second explanation when
  one phrasing doesn't land.

- NamasteDSA course (Akshay Saini) — Time & Space Complexity section
  The course being followed. Use for: staying aligned with the course's vocabulary and
  problem set.

## Wisdom (Communities)

- [r/leetcode](https://www.reddit.com/r/leetcode/)
  Active, interview-focused. Use for: "is my complexity analysis right?", sanity-checking
  approaches, seeing how others explain trade-offs in real interviews.

- [LeetCode Discuss — per-problem solution threads](https://leetcode.com/discuss/)
  Every popular problem has threads debating O(...) of each approach. Use for: comparing
  your analysis of a specific problem against a crowd.

- [Namaste Dev / Akshay Saini community](https://namastedev.com/)
  The course community. Use for: questions tied to the course's exact framing.
