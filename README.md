# NamasteDSA

Solutions to problems solved as part of the NamasteDSA course by Akshay Saini, written in JavaScript.

## Structure

Problems are grouped by the section they appear in during the course.

```
namasteDSA/
├── arrays/
│   └── removeDuplicates.js
└── warmUp/
    ├── countDigits.js
    ├── countNegatives.js
    ├── findLargest.js
    ├── palindrome.js
    ├── reverse.js
    ├── searchElement.js
    └── secondLargest.js
    └── starPattern.js
```
